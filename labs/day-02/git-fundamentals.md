# Day 2 - Git Fundamentals

## Objectives
- Understand the Git workflow.
- Practise staging and committing changes.
- Learn to inspect changes and commit history.

## Commands Practised
- git status
- git add
- git commit
- git log
- git diff
- git push

## Key Learnings
- Working directory: where files are edited.
- Staging area: where changes are selected for a commit.
- Local repository: where commits are stored.
- Remote repository: where changes are shared on GitHub.
